## Rào cản
- Vốn và dòng tiền
- Kỹ năng số của đội ngũ
- Dữ liệu khách hàng phân tán
- Thiếu thời gian để thử nghiệm
- Thiếu cố vấn và mạng lưới tin cậy
- Rủi ro an ninh mạng và dữ liệu cá nhân

## Nhu cầu
- Doanh thu: tìm khách, nuôi dưỡng khách, tăng  chuyển đổi
- Chi phí: giảm thời gian soạn nội dung,  báo cáo, chăm sóc lặp lại
- Năng suất: chuẩn hóa quy trình chuẩn, đào tạo nội bộ, toongrh ợp dữ liệu
- Ra quyết định: so sánh phương án, phát hiện rủi ro, đặt câu hỏi tốt hơn

- Cần tích hợp: hệ thống quản lý khách hàng và trợ  lý trả lời tự động, bảng theo dõi số liệu bán hàng, tự động hóa quy trình
- Không giao hoàn toàn: pháp lý, tài chính nhạu cảm,  tuyển dụng  cuối cùng
