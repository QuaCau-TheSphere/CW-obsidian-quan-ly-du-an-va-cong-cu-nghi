Khái niệm:: 
Giới học thuật Việt Nam thường dịch lẫn lộn Ontologie thành “Bản thể học”. Tuy nhiên, chúng tôi chủ trương phân định rõ hai khái niệm gốc Hy Lạp: 
- Hữu thể học (Ontologie): Bắt nguồn từ chữ ontos (sự tồn tại). Nghiên cứu phạm trù bao quát nhất về sự “có”/hiện hữu nói chung của vạn vật; 
- Bản thể học (Ousiologie): Bắt nguồn từ chữ ousia (thực thể/bản thể cốt lõi), là khái niệm hẹp hơn của Aristotle, chuyên nghiên cứu về “gốc rễ” - cái tạo nên bản chất căn cốt, bất biến của một sự vật cụ thể.
